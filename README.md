# Machine-Yearning
The collection of CAD files and software for Machine Yearning - a pair of non-humanoid, wearable robotic limbs controlled by BCIs from OpenBCI.

## Repository Structure

### Hardware
Contains mechanical hardware designs for the robotic limbs:
- **tentacle-arm/** - CAD files and bill of materials for the tentacle arm design
- **jointed-arm/** - CAD files and bill of materials for the jointed arm design

### Electronics
Contains electronics documentation and bill of materials for all electronic components.

### Software
Contains software, control code, and instructions for operating the robotic limbs.
